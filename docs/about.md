# 关于 OpenDS

OpenDS 是一个持续更新的个人学习档案，汇集在复旦大学大数据学院学习期间形成的课程笔记、作业解答、项目代码、自学资源和其他材料。

它首先服务于自己的复习和知识整理；如果这些记录也能帮助后来者少走一点弯路，那就更好了。

<div class="about-panel">

## 如何使用

- 从[课程地图](/courses/)找到课程，在站内连续阅读 Markdown 笔记；PDF、实验代码和附件仍保留在 GitHub。
- 使用顶部搜索框查找课程介绍、笔记正文和学习资源。
- 文件可能包含错误或过时内容，请结合教材、课堂说明和自己的推导进行验证。
- 作业与项目内容应作为学习参考，请遵守所在课程的学术诚信要求。

</div>

## 参与改进

如果发现错误、失效链接或更清楚的解释，可以：

1. 在 [GitHub Issues](https://github.com/hadanice/OpenDS/issues) 描述问题；
2. 直接编辑站点页面并提交 Pull Request；
3. 提交修改时说明课程、文件位置和修改理由。
